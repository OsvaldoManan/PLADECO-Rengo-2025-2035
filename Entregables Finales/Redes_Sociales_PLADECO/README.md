## 📝 Cómo publicar

### Instagram
1. Abrir Instagram → "+" → Publicación
2. Seleccionar imagen 1080×1080 desde `posts/`
3. Pegar caption desde `Captions_Redes_Sociales_PLADECO.docx`
4. Etiquetar `@munirengo` y ubicación "Rengo, Chile"
5. Publicar simultáneamente en Facebook (sincronización)

### Stories
1. Abrir Instagram → Story
2. Seleccionar imagen 1080×1920 desde `stories/`
3. Agregar sticker de ubicación, hashtag y mención
4. Compartir también en WhatsApp Estados

### Facebook
1. Crear publicación → Foto/Video
2. Subir imagen 1080×1080
3. Pegar caption (el mismo de Instagram)
4. Programar para horario peak

## ✏️ Cómo modificar el contenido

El script `crear_redes_sociales.py` es reproducible. Para cambiar:
- **Cifras**: editar las variables en cada función `post_XX()`
- **Colores**: modificar diccionario `COL` al inicio
- **Texto**: editar las strings dentro de cada `post_XX()`
- **Layout**: ajustar coordenadas (W, H = 1080, 1080)

Después correr `python crear_redes_sociales.py` y se regeneran todos los posts.
